# Valorant Snapshot Analysis

## Overview
This project analyzes Valorant match snapshot data to identify patterns and trends that may influence round outcomes.

## Analysis
The project uses command-line tools to:
- Create frequency tables
- Find Top-N results
- Build skinny tables for selected variables
- Compare gameplay factors with round winners

## Tools Used
- Linux/Ubuntu
- Bash
- `cut`
- `sort`
- `uniq`
- `head`
- `wc`
- `tee`

## Goal
The goal is to practice shell-based data processing while discovering meaningful patterns in Valorant match data.
